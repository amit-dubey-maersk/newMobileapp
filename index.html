Architecture notes

The SAP route is permanent; the Trinium EDI bridge is interim. SAP updates return to TMS; SAP events go only to EM. The workflow illustrates message direction and sequence, not live traffic. Geofences and mapped IAM driver identities accompany each Trinium mobile load. Documents flow via Mobile Backend → Drayconnect in Azure → Trinium API.
